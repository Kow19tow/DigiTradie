# DigiTradie logo concepts

Twelve directions drawn from the social posts. Each folder has `icon.png` (1024px, transparent), `lockup-on-dark.png`, `lockup-on-light.png` (transparent) and, where the icon is pure vector, `icon.svg`.

- `contact-sheet.png` - all 12 side by side on dark and on the site cream.
- `small-size-test.png` - every icon at 128/64/32/16px (favicon test).
- `source/build_logos.py` - regenerates everything: `python3 brand/logo-concepts/source/build_logos.py` (needs Chrome + pillow).

These are concepts, not final brand files. The wordmark uses Bricolage Grotesque (the site font); a chosen logo should be outlined to paths before print or wide distribution.
